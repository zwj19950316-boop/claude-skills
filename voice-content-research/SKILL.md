# Voice Content Research & Script Generation

Research voice changer content trends for a specific game character on YouTube and TikTok, analyze popular video patterns, categorize script types, and generate a customized video script tailored to the character's positioning.

## When to Use

- User wants to know if there's demand for a game character's voice changer content
- User wants to find popular voice changer videos for specific game characters
- User wants to analyze content patterns and script types for voice changer videos
- User wants a ready-to-shoot video script for a specific character

## Workflow

### Step 1: Demand Research

Search across YouTube and TikTok for the character's voice changer presence:

```
WebSearch query: "{character} voice changer YouTube"
WebSearch query: "{character} voice changer TikTok"
WebSearch query: "{character} AI voice generator {game}"
```

Look for signals of demand:
- Existing voice changer tools with the character's preset
- Video titles mentioning "sound like {character}"
- TikTok topics around the character's voice
- Community discussions about the character's voice (AI-sounding, robotic, etc.)

### Step 2: Benchmark Video Collection

For 3-5 comparable characters (established/popular ones in the same game), search for voice changer videos from the past year:

```
WebSearch query: "{benchmark character} voice changer YouTube 2025 2026 views"
WebSearch query: "{benchmark character} AI voice changer TikTok viral 2025"
```

For each character, collect 5-10 videos ranked by views/engagement. Record:
- Title, URL, platform, view/like count, date
- Content type (trolling, tutorial, roleplay, etc.)
- Tools mentioned (Dubbing AI, Voice.ai, Voicemod, etc.)

### Step 3: Script Pattern Analysis

Analyze the benchmark videos to identify 3 distinct script categories. For each category, define:

1. **Core hook** — what grabs attention in the first 3 seconds
2. **Structure template** — the beat-by-beat flow of the video
3. **Why it works for specific characters** — character traits that match the script type
4. **Typical video examples** — real videos that follow this pattern
5. **Platform fit** — which platform(s) this type performs best on

Expected categories (names may vary):
- **Trolling / 恶搞型** — recording teammates' reactions to the character's voice
- **Tutorial / 工具型** — teaching viewers how to use a voice changer to sound like the character
- **Roleplay / 沉浸体验型** — fully embodying the character's personality in voice chat

### Step 4: VoiceWave Product Introduction

Before the character script, include a dedicated VoiceWave product introduction section that showcases the tool's capabilities:

**VoiceWave 核心卖点 (Core Selling Points):**

| 卖点 | 说明 | 视频应用 |
|------|------|----------|
| **超低延迟** (<10ms) | 实时变声，游戏/语音聊天零卡顿 | 直播、游戏trolling无缝衔接 |
| **1000+ 音效库** | 涵盖游戏、动漫、电影、meme等分类 | 随时切换音效增强角色表现力 |
| **AI 声音克隆** | 上传音频即可克隆任意角色声音 | 自定义专属{character}声线 |
| **Soundboard 快捷键** | 支持自定义快捷键播放音效 | 直播中快速插入经典台词/音效 |
| **多平台支持** | Discord、Steam、Zoom、OBS等 | 一站式覆盖所有语音场景 |
| **背景降噪** | 智能过滤环境噪音 | 保证变声清晰度 |

**产品介绍脚本片段 (用于视频中部):**
- 展示 VoiceWave 界面
- 演示选择{character}预设的过程
- 强调"一键切换"的便捷性
- 展示Soundboard播放经典台词

### Step 5: VoiceWave Tutorial Section

Add a mini-tutorial segment (60-90 seconds) showing viewers how to set up the character voice:

**教程结构:**
1. **下载安装** (10s) - 官网链接 + 安装过程
2. **选择预设** (15s) - 在音效库搜索{character}
3. **参数微调** (20s) - 音调、混响、失真度调整
4. **Soundboard设置** (15s) - 添加角色经典台词到快捷键
5. **测试效果** (20s) - 对比原声 vs 变声
6. **CTA** (10s) - "链接在简介，免费下载体验"

**界面展示要点:**
- 高亮显示音效搜索栏
- 展示分类标签(游戏/动漫/恐怖等)
- 录制设置面板 (输入/输出设备选择)
- Soundboard面板布局

### Step 6: Character Script Generation

Based on the character's traits (voice style, personality, lore, community memes), select the best-matching script category and generate a complete video script:

**Output structure:**

1. **标题方向** — 3 clickable title options
2. **平台定位** — recommended platform and format (vertical/horizontal, duration)
3. **脚本正文** — timestamped script with:
   - **Part 1: 开场Hook** (0:00-0:30) - 用VoiceWave变声直接开场
   - **Part 2: 产品介绍** (0:30-2:00) - VoiceWave功能展示
   - **Part 3: 使用教程** (2:00-3:30) - 快速上手指南
   - **Part 4: 内容主体** (3:30-8:00) - 角色trolling/roleplay内容
   - **Part 5: 互动Outro** (8:00-10:00) - 总结 + CTA
   - Visual cues (what's on screen)
   - Audio/dialogue (what's said, including character voice vs normal voice)
   - Specific lines to use (character quotes, meme references)
   - Interaction rounds (for trolling type: 2-3 rounds of teammate reactions)
4. **关键执行要点** table:
   - 变声工具: VoiceWave (specific preset/settings)
   - VoiceWave音效预设推荐
   - Soundboard配置建议
   - 录制方式
   - 视觉风格
   - BGM suggestion
   - Hashtags
   - 互动引导 (comment/engagement hook)
5. **为什么适合这个角色** — 3-4 bullet points explaining the fit

### Step 7: Benchmark Comparison Summary

Provide a comparison table showing:
- Which character fits which script type best
- Relative content heat (high/medium/low)
- Primary content style per character
- Dominant tools per character

## Key Guidelines

- **Prioritize recency**: Focus on videos from the past 12 months
- **Cross-platform**: Always search both YouTube and TikTok
- **Look for memes**: Community jokes about a character's voice (e.g., "sounds like AI") are free engagement hooks
- **Tool awareness**: Focus on VoiceWave as the primary tool, with its core features (low latency, 1000+ effects, Soundboard, AI voice cloning)
- **Product integration**: Always include VoiceWave introduction and tutorial segments in the script
- **Actionable output**: The final script should be ready to record, not just a concept
- **Character-first**: Match the script type to what makes the character unique, don't force a template
