# 报告模板说明

## 报告用途

本模板定义了热点调研报告的标准结构和内容规范，确保每次生成的报告格式统一、信息完整。

## 报告结构

### 1. 执行摘要

- **报告日期**: YYYY年MM月DD日
- **监测领域**: Windows系统 / 数据恢复 / 存储设备
- **数据来源**: Google / YouTube / X(Twitter) / Facebook
- **品牌**: EaseUS

关键指标：
- 热点话题总数
- P0/P1/P2级选题数量
- 竞品动态数量

### 2. 热点话题排行

每个话题包含：
- **热度评分**: 1-10分（基于搜索量、互动量、时效性、跨平台覆盖）
- **优先级**: P0（立即）/ P1（本周）/ P2（储备）
- **产品关联**: 强/中/弱/无
- **来源平台**: 出现在哪些平台
- **相关链接**: 原始来源URL
- **热度指标**:
  - Google搜索提及次数
  - YouTube相关视频数量
  - Twitter讨论量
  - Google News报道数
  - 最高互动量
  - 最新内容时间
- **EaseUS结合建议**:
  - 可直接结合产品 / 软性植入 / 行业资讯
  - 具体选题角度建议

### 3. 竞争对手内容追踪

每个竞品包含：
- **频道/账号名称**和粉丝量
- **最新内容列表**（标题、观看量/互动、发布时间）
- **策略观察**:
  - 发布频率
  - 热点响应速度
  - 是否涉及数据恢复/分区管理（直接竞品动作）
  - 可借鉴/差异化点

### 4. 建议选题角度

按优先级分类：

#### P0 — 立即跟进（48小时内）
- 热度≥8分且与EaseUS产品强相关
- 内容形式和平台建议
- 参考素材链接

#### P1 — 本周跟进
- 热度6-7分或有一定产品关联
- 可深度结合产品功能

#### P2 — 长期储备
- 热度4-5分
- 观察趋势发展

### 5. 数据附录

- 本次搜索使用的关键词列表
- 数据来源时间戳
- 原始数据文件路径

## 热度评分算法

| 维度 | 说明 | 最高分 |
|-----|------|-------|
| 基础分 | 各平台提及次数 × 0.5 | 3分 |
| 互动分 | 平均互动量（观看/点赞） | 2分 |
| 时效分 | 24h内+3, 3天内+2, 7天内+1 | 3分 |
| 新闻分 | Google News出现 | 1分 |
| 跨平台分 | 覆盖≥3个平台 | 1分 |
| **总计** | | **10分** |

## 选题优先级规则

| 热度评分 | 产品关联 | 优先级 |
|---------|---------|-------|
| ≥7 | 强/中 | P0 |
| ≥6 或 ≥5 | 任意 / 强 | P1 |
| ≥4 | 任意 | P2 |
| <4 | 任意 | 不列入 |

## 内容形式建议

根据话题类型推荐内容形式：

| 话题类型 | 推荐形式 | 目标平台 |
|---------|---------|---------|
| 教程/How-to | 3-5分钟短视频 + 长视频 | YouTube + TikTok |
| 产品测评 | 8-15分钟深度视频 | YouTube |
| 热点资讯 | 图文/短动态 | Twitter/X + Facebook |
| 数据恢复场景 | 剧情化短剧/情景演示 | TikTok + YouTube Shorts |
| 系统问题修复 | 分步教程长视频 | YouTube |
