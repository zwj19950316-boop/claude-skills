#### 场景 1：SD 卡数据恢复（Windows）

- **常见数据丢失原因**：
  1. 误格式化：在磁盘管理或文件资源管理器中误选错误分区进行格式化
  2. 系统提示格式化：设备插入后Windows提示"使用驱动器X: 中的磁盘之前需要将其格式化"

  4. 相机/设备格式化：在相机、手机、游戏机等设备中误操作格式化存储卡
  5. 快速格式化：为了快速清空设备而执行快速格式化
  6. 完全格式化：使用"完整格式化"选项，Windows会对每个扇区写入零
  7. 分区工具误操作：使用Partition Master等工具时误格式化分区
- **免费方案**：
  - Windows File Recovery：微软官方命令行工具，支持格式化后恢复
  - PhotoRec：开源免费，基于文件签名恢复，支持格式化场景
  - TestDisk：开源免费，专注于分区表修复和格式化恢复
  - 立即停止使用设备：格式化后停止写入新数据，提高恢复成功率
- **免费方案局限性**：
  - Windows File Recovery：命令行界面操作复杂，普通用户难以掌握；需要准确知道文件扩展名和存储路径；错误的命令可能导致更多数据丢失；对完全格式化（写入零）后的恢复效果极差
  - PhotoRec：恢复时完全丢失文件夹结构和原始文件名，所有文件按类型混在一起（如所有照片在一个文件夹），需要手动整理；界面简陋，仅命令行操作；无法恢复碎片化严重的文件
  - TestDisk：专注于分区表恢复，对文件级恢复支持有限；操作极其复杂，需要理解分区表、引导扇区、文件系统结构等专业知识；操作错误可能导致分区永久丢失或进一步损坏
  - 格式化后继续写入：继续使用设备会覆盖原数据，一旦数据被覆盖任何工具都无法恢复；快速格式化后数据区域实际上未被清空，但新数据写入会直接覆盖
  - 完全格式化限制：Windows的"完整格式化"会向每个扇区写入零，这种情况下即使是付费软件也无法恢复数据

- **适用设备/情况**：显示为RAW格式的硬盘分区、USB驱动器、SD卡；文件系统损坏导致Windows无法识别的存储设备

  3. 病毒攻击：恶意软件破坏文件系统或分区表
  4. 分区表错误：分区表损坏或丢失导致无法识别文件系统
  5. 坏扇区：硬盘出现物理坏扇区影响文件系统元数据
  6. 系统崩溃：操作系统崩溃导致分区信息丢失
  7. 不兼容的文件系统：将Linux格式化的磁盘直接连接到Windows
- **免费方案**：
  - chkdsk命令：使用`chkdsk X: /f`尝试修复文件系统错误
  - TestDisk：开源免费，专门用于分区表修复和RAW恢复
  - DiskPart：使用Windows磁盘管理工具尝试重新分配驱动器号
  - 转换为动态磁盘：Windows磁盘管理中的高级选项
- **免费方案局限性**：
  - chkdsk /f命令：对于严重损坏的RAW驱动器，chkdsk可能报告"文件系统的类型是RAW，CHKDSK无法供RAW驱动器使用"；在某些情况下，强制运行chkdsk可能进一步损坏已损坏的文件系统，导致数据永久丢失；无法恢复被覆盖的数据
  - TestDisk：操作极其复杂，需要专业技术知识，包括理解分区表结构、引导扇区、文件系统类型等；操作错误可能导致分区永久丢失或数据进一步损坏；没有图形化界面，纯命令行操作对普通用户极不友好；主要用于分区恢复而非文件级恢复
  - DiskPart/动态磁盘：这些操作具有破坏性，可能导致数据永久丢失；Windows会提示格式化RAW驱动器，但格式化会清除所有数据；不当操作可能使恢复变得更加困难甚至不可能
  - RAW信号严重性：RAW状态通常是严重逻辑损坏的信号，免费工具的成功率有限；物理损坏（磁头损坏、电路板故障）无法通过任何软件工具修复
- **DRW 核心差异点**：支持RAW驱动器的深度扫描，无需格式化即可直接读取损坏的存储设备；通过扇区级分析绕过损坏的文件系统，直接搜索文件签名和残留数据；提供文件预览功能，用户可以在恢复前查看可恢复文件的内容，避免恢复损坏或无用的文件；针对不同类型的RAW损坏提供智能恢复策略，能够处理因突然断电、强制拔出、病毒攻击等多种原因导致的RAW状态，支持照片、视频、文档、音频等1000+种文件类型的恢复。
