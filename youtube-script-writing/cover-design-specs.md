# 封面设计规范

**封面设计checklist：**

- [ ]  Text, font, contrast — easy to read ([Iman Gadzhi](https://www.youtube.com/@ImanGadzhi/videos))
- [ ]  Relevant visuals — support topic of video / create curiosity ([Alex Hormozi](https://www.youtube.com/@AlexHormozi/videos))
- [ ]  Face — improve click-through-rate ([magazine covers](https://www.google.com/search?rlz=1C5CHFA_enVN1019VN1019&sxsrf=AB5stBi7DEB4fJ6tddQhSPXm4hpxIN6FSQ:1690185866388&q=magazine+cover&tbm=isch&source=lnms&sa=X&ved=2ahUKEwi1-q2B8aaAAxVuklYBHfn9BxQQ0pQJegQIDBAB&biw=1800&bih=1046&dpr=2), [Think Media](https://www.youtube.com/@ThinkMediaTV/videos), [Chris Williamson](https://www.youtube.com/@ChrisWillx/videos))
- [ ]  Small devices — clear to see what’s happening in < 1 second ([Waveform Clips](https://www.youtube.com/@WaveformClips/videos))
- [ ]  No text in bottom right corner - timestamp will cover it
- [ ]  Brand consistency — zoom out & see what it looks like on grid, i.e. “Is it on brand?” ([DOAC](https://www.youtube.com/@TheDiaryOfACEOClips/videos), [Youshaei](https://www.youtube.com/@youshaei/videos))

- [ ]  Skin tone consistency — person should look the same
- [ ]  Brightness consistency — adjust exposure levels
- [ ]  Increase brightness/vibrancy as high as realistically possible ([MrBeast](https://www.youtube.com/@MrBeast/videos))
- [ ]  File size under 2MB

**youtube 封面设计要求：**

YouTube 封面（缩略图）的标准尺寸要求：

**推荐尺寸：1280 × 720 像素**（16:9 比例）

- 最小宽度：640 像素
- 文件大小：不超过 **2MB**
- 格式：JPG、PNG、GIF、BMP（推荐用 JPG）
- 比例：**16:9**（这是 YouTube 播放器的标准比例）
